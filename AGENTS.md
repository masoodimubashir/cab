# Project continuity

For Android signing, Firebase migration, Play Store readiness, or resuming the
September 2026 release work, read `docs/Android-Release-Handoff.md` first, then
`docs/Google-Play-Release-Setup.md` for build instructions.

The handoff is a dated record, not proof of current Console or production status.
Update it when relevant work is completed, separating local evidence, user-reported
status, and external verification. Never store passwords or private keys in notes.
